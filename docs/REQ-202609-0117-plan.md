# REQ-202609-0117：后台管理页面 UI 优化

## 需求背景

- **需求编号**：REQ-202609-0117
- **目标**：优化后台管理界面的 UI 交互，引入现代化的 macOS 质感（例如模糊、圆角、层次感更强的输入框和列表），并在某些搜索框（如 users 页面、cases 页面等）后增加明显的搜索按钮，以改善“过于简陋”的用户体验。
- **操作原则**：看代码定需求 -> 编写此技术方案 -> 修改代码。

## 现状分析

通过查看 `/src/app/admin/layout.tsx`，`/src/app/admin/users/page.tsx` 和 `/src/app/admin/cases/page.tsx`，发现以下几点：
1. 布局比较基础，采用普通的 border 和深浅色块，质感欠缺。
2. 搜索框部分（如 users 页面 `input` 和 cases 页面的搜索 `input`）虽然有 `onChange` 触发请求/状态改变，但缺乏显式的“搜索”按钮以及视觉上的搜索容器包裹。
3. 表格（Table）和分页等组件样式中规中矩，可以加入更现代的细节处理：稍大的圆角（xl）、阴影、半透明背景模糊（macOS 的毛玻璃效果，Tailwind 的 `backdrop-blur-md`）、细致的过渡动画。

## 优化技术方案

我们将实施三层改进：

### 1. 结构和布局的微调（增加搜索按钮）
针对带有搜索功能的页面（`users` 和 `cases` 等）：
- 将孤立的 `input` 元素包裹在一个带有毛玻璃效果（如 `bg-white/80 dark:bg-[#1a1a1a]/80 backdrop-blur-md`）和轻微阴影的容器中。
- 搜索框旁添加一个明确的**“搜索” (Search) 按钮**（如果有图标可以结合图标，或者使用简洁的文字按钮），用于主动触发或者提供视觉指引（即使当前是输入即搜索）。

### 2. 引入 macOS 质感与人文关怀
**全局与容器质感**：
- 替换平淡的纯色容器背景，增加类似 macOS 的轻透光感效果（`backdrop-blur` 和 `bg-opacity`）。
- 加大圆角使用：`rounded-lg` 升级为 `rounded-xl` 或 `rounded-2xl`，例如将列表外部包裹容器增加阴影 `shadow-sm`。

**表格样式优化**：
- 表头加入更柔和的背景色，如 `bg-gray-50/50 dark:bg-[#141414]/50` 和模糊效果。
- 表格行（Row）添加更为丝滑的悬停过渡动画（`transition-all duration-200`）。

**按钮样式优化**：
- 为主要的控制按钮添加更为细腻的光影：主按钮使用渐变和轻微阴影，例如 `shadow-sm shadow-gray-200/50`。

### 3. 具体实施文件与修改点

1. `src/app/admin/users/page.tsx`：
   - 修改顶部的搜索区域，将 input 和新增加的搜索按钮（“Search”或者放大镜图标，通过执行 `fetchUsers(page)`）封装进统一的圆角容器内。
   - 给 Table 容器添加 `backdrop-blur-sm bg-white/70 dark:bg-[#0d0d0d]/70 shadow-sm rounded-2xl`。
   - 美化分页器。

2. `src/app/admin/cases/page.tsx`：
   - 修改筛选栏（Filters），重构 input 为搜索组合框并添加 Search 按钮。
   - 升级表格容器样式与 users 页面保持一致的质感。
